# 🏋️ Fitness & Exercise Planner

A modern and responsive **Fitness & Exercise Planner** built with **Next.js, TypeScript, and Tailwind CSS**.

This application helps users explore exercises, create a daily workout plan, save exercises, and manage their fitness activities through an interactive dashboard.

## ✨ Features

* 🏋️ Browse different exercises
* 🔍 Explore exercise details
* 📋 Create a daily workout plan
* 💾 Save favorite exercises
* ✅ Manage today's workout plan
* 📊 Fitness dashboard
* 🔄 Add and remove exercises from plans

## ⚙️ Getting Started

First, clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project directory:

```bash
cd your-project-name
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```
